# Exo Launcher — domain

A Windows 11 launcher. Steam, Epic, GOG, Riot and the other official clients stay where the vendor installed them; Exo commands them and hides their chrome. It is not a DRM, ownership or anti-cheat bypass.

## Glossary

| Term | Meaning |
| --- | --- |
| **Exo Launcher** | This app: a WinUI 3 / .NET host that spawns the native Rune UI (`exo-ui.exe`, `native-ui/`) by default, with classic React 19 in WebView2 (`ui/src/`) as the fallback. Native rooms: Library, Store, Discord, Music, Devices, Exo AI, Apps; Settings is the gear. Classic has PC in place of Exo AI and Apps. GOG and Epic sign-in use a short-lived WebView2 window of their own (`Services/StoreAuthWindow`). |
| **Exo Island** | The Bar's live capsule left of the room tabs: a Discord call outside the room. Nothing live, nothing drawn. |
| **Library** | Installed and owned-not-installed titles as covers, with Continue and folders. Details open as a sheet over it. |
| **Store backend** | The official client Exo detects and commands. Its files are never copied into Exo. |
| **Steam IPC** | `ExoLauncher.SteamIpc` via `steamclient64.dll`. Install/update/uninstall proof is ACF `BytesDownloaded`, not Steam chrome. |
| **Legendary** | Epic agent. |
| **gogdl** | GOG agent. |
| **Local debug build** | `Run-ExoLauncher.ps1` → `ExoLauncher\bin\x64\Debug\…\ExoLauncher.exe`; it picks up `native-ui\target\release\exo-ui.exe` when that is built. |
| **Exo AI** | The native room for this PC: graphics, display and board part menus, storage, Auto tune and Exo Shaders (`pc_ai.rs`, `pc_menus.rs`, `pc_storage.rs`). With Apps it replaces classic's PC room. |
| **Exo Voice** | Exo's own voice cleanup for calls and the microphone (`exo-voice-ml`; Devices › Audio). |
| **Shipped install** | `%LOCALAPPDATA%\ExoLauncher\app\ExoLauncher.exe`. After host or UI changes, publish and swap it in with `tools\swap-dev.ps1` (AGENTS.md › Ship). |
| **Upscaler swap** | User-requested replacement of DLSS / FSR / XeSS files the game already ships, with official files pinned by SHA-256, after a first-shipped `.dlsss` backup. Never in games with anti-cheat (`AntiCheatCheck`: store, files, services, Steam's word, title) unless the user allowed it for that game after a ban-risk confirmation (settings `upscalerAntiCheatConsent`, tied to the anti-cheat named); never in Riot games or with Riot Vanguard. A file an upscaler mod put in (HelixSR, OptiScaler, DLSS Enabler and others, by their marker files and folders, `DlssSwapService.Mods.cs`) is the mod's: never updated or restored over, and shown by the mod's name. OptiScaler and DLSSG SM86 go in only as Frame generation (below). Not applied on Play. |
| **Frame generation (mod)** | Exo's choice, with one switch: Best settings' Frame generation in games without anti-cheat, off until turned on; turned off, it takes the mod out of every game. A game's line only reads what it found. Exo picks the package per game (`DlssSwapService.FrameGen.cs`, `FrameGenAuto.cs`), a mod beside the game's program so the game's own DLSS Frame Generation switch works. An RTX 20/30 whose game speaks DLSS frame generation 310 or newer through Streamline 2 on DirectX 12: DLSSG SM86 (NVIDIA's model, preset A at 2x) while Exo offers it, which is one pin in code (`PinnedFrameGenReleases`; none today, so earlier installs stay and work but none go in); else, and once if DLSSG SM86 can't go in or fails its first session, OptiScaler with FSR frame generation, as every other card gets it. OptiScaler on GeForce GTX 900 and newer, Radeon RX 400 and newer (Vega included), Radeon 600M and newer, Z1/Z2 and Ryzen AI graphics, Intel Arc and Arc graphics; a game with its own says Built into the game. An RTX 40 or 50 has NVIDIA's own and gets no mod. Each mod's release is pinned in code by size and SHA-256 and comes from Exo's cache; kept current while no game runs, the release before kept to go back to when a session fails. Never in a game with anti-cheat, Riot never, and never back in one whose first session failed; taken out before launch if anti-cheat appears, a patch changes the game's program, the game stops shipping DLSS Frame Generation or the card no longer needs it. Another mod over Exo's loader is left alone and keeps the game off; files of Exo's that went go back once. Off removes every file Exo wrote that is still Exo's (checked by SHA-256), keeps the rest, removes what the mod wrote beside it, and puts back OptiScaler's NVIDIA profile frame cap. |
| **Uninstall / Remove** | Uninstall removes a store game through its store; Remove takes a game added from a folder or .exe out of the Library and leaves its files. Two clicks (the button, then Confirm). |
| **Discord** | The room that is Exo's own Discord client (`discord.*`, `Services/DiscordClient`; the room's id is still `friends`, and a saved place's `friends` is the Home place): Discord's servers, DMs, messages and calls drawn by Exo. Inside, one list holds **Now** (the voice rooms friends are in, what they play, what is unread), **Friends**, your conversations and your servers as rows. Discord owns the account and data; Exo has no roster, profile or social service of its own. The Discord desktop app is not hosted. |
| **Music** | Exo's own player over the selected service, which runs hidden as the engine and is driven through its own APIs: Spotify's web player (`spotify.*`, the platform APIs and GraphQL its own UI uses), Apple Music's web player (`applemusic.*`, the MusicKit instance music.apple.com sets up), YouTube Music's web player (`ytmusic.*`). Exo never handles audio, tokens or entitlements. The mini player's song comes from the service's page and its volume is the app's own. No native MusicKit or Spotify SDK. |
| **Exo account** | Required for everyone (owner, 2026-11-09): email and password at `accounts.getexo.app` (`Services/Account`, the live Worker's source in `cloud/account`). Setup asks for it right after Welcome and, while a PC is signed out, Exo opens on the account screen at every start, with no skip; only an unreachable service lets **Continue without an account** through until it answers. It syncs the player's choices and playtime (`PlayerData.cs` says what and how). The service holds a keyed digest of the email, never the address. |
| **Anti-cheat check** | `Services/AntiCheatCheck.cs`: the one answer to "does this game run anti-cheat?", from evidence on disk (store, known game, anti-cheat folders, files and stubs, services, Steam's own word, and the title list, which always counts). Unknown (a folder that cannot be read) counts as yes: the code refuses every change there, whatever it is; only the game's own interface (settings file, launch arguments) and, with consent, the vendor's signed upscaler file are allowed where anti-cheat is found; Riot and Vanguard never. Exo never changes Riot's games or Vanguard's driver and service. It may hide and close the Riot Client's windows, ask it to quit, switch its signed-in account, and, if you choose, take Vanguard's tray icon out of start-up. |
| **Exo app** | Retired with Optional keys: Exo ships and asks for no developer credentials. Users only Sign in / Connect. |

Retired and deleted, not to be revived: the Optimize room and `optimize.*` RPCs; the Exo roster/Profile rooms and `friends.*`/`profile.*`/`online.*` social RPCs (`friends.badge` is the Discord room's unread count); the older optional account of Exo 3.3 and 3.4 (`online.*`, the exo-id service, handles, badges; its service no longer exists), which is not the Exo account below; the Exo Store (client, bridge calls, Worker and settings, removed in 3.26); the Discord Social SDK; the hosted Discord desktop app (its install, update repair, Equicord patch, `friends.setBounds`/`status`/`install`/`open` and the `discordNative` setting); native MusicKit/Spotify SDK players; the hosted Spotify desktop app (`DesktopClientHost`, `desktopClients.*`, `music.install`, its install and Store-edition switch, `SpotifyDevTools`, the xpui patch); the Exo Jam sheet; the native mirror UI models under `ExoLauncher/Ui`. Not in the v4 native UI: Notes, Frame Cap and G-SYNC, Graphics Features (folded into Optimize), GPU activity; PC is split into Exo AI and Apps.

## Avoid

- Treating Exo as a DRM or ownership bypass. Exo sells nothing: the Store room's buttons open the vendor's own store.
- "DepotDownloader", nested Steam, OCR/SendInput as the Steam install path.
- Killing `vgk` / `vgc` / Vanguard / EAC / BattlEye.
- Product names other than Exo Launcher (and Exo's own parts: Exo AI, Exo Voice, Exo Capture, Exo Mouse, Exo Shaders).
- Reviving Optimize or shipping it as a separate Exo Hub exe.
