- Decided by: owner, 2026-11-07
- Status: superseded: Exo Launcher is open source under MIT at github.com/UhhErix/Exo-Launcher, and changes land through pull requests against `main` (AGENTS.md › Ship, Public pages and license)
- Detail: `misc/off-github.md`, `..\AGENTS.md`

getexo.app is the public face (download, help, changelog, feed, source, privacy). The apps are source-available under `LICENSE` (read and check only; no copying, forking or changed versions without written permission), and Exo Launcher's own source is not published. Nothing is pushed to github.com/UhhErix/ExoLauncher or any other GitHub repo, and no `gh` command is run; those repos stay as they are until the owner decides to archive them. The off-site copy of the code is `..\tools\backup-git.ps1` (R2 `exo-git-backup`).
