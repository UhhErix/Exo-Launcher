# Telemetry and crash reports are always on

- Decided by: owner, 2026-11-09
- Status: in force; replaces the opt-in of 3.25
- Rule: AGENTS.md › Hard stops (consent)

Exo's own app telemetry and crash reports are essential data, so every install sends them, with no switch. They stay anonymous: a random install ID, schema-checked and scrubbed on the PC, never an account, a name or hardware. PRIVACY.md lists exactly what is sent, and Settings › Privacy keeps What's sent and Delete my data. Third-party analytics stay banned.
