# Exo Launcher — agent instructions

The launcher lives in `apps/launcher/`. Its working rules are in [`apps/launcher/AGENTS.md`](apps/launcher/AGENTS.md): read that file before changing anything, and run commands from `apps/launcher/` unless it says otherwise. Since 4.0.0 the default UI is native (`apps/launcher/native-ui/`, Rust on Rune); classic React (`apps/launcher/ui/`) is the fallback.
