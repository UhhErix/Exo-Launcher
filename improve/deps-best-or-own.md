## Executive Summary & Real-PC Footprint Baseline

### Test Machine & Methodology
Every local benchmark below was executed on this PC on 2026-11-24 against real installed Exo binaries (`%LOCALAPPDATA%\ExoLauncher\app`, 380.02 MB across 1,039 files), real installed update diffs (`app.previous-dev-87d74c3eb7ae4e12b3c2e9e3841d6158` → `app`), real cached cover art (`covers/`: 1,315 files / 227.5 MB; `cache/rune-art/`: 1,201 files / 127.5 MB), and real installed ML models (`titanet_small.onnx` 38.39 MB; `exo-deepfilter.dll` 50.64 MB):

- **CPU:** AMD Ryzen 5 5600X (6C/12T @ 3.7 GHz, AVX2 / FMA / BMI2 / SHA-NI; **no AVX-512**)
- **RAM:** 15.9 GB
- **GPU:** NVIDIA GeForce RTX 3070 (Driver 32.0.16.2135)
- **OS / Toolchains:** Windows 11 x64 (`10.0.26300`), `rustc 1.100.0`, `.NET 10.0.403` (runtime `10.0.15`)
- **Transparency note:** Other background builds shared the CPU during initial Rust sweeps; multi-pass clean runs were executed for `exo-wire` cross-process pipes and allocators. Capabilities that could not be executed locally (AVX-512, ONNX DirectML/CUDA/TensorRT/OpenVINO EPs because those native EP binaries/SDKs are not installed in this environment, and a full raw-D3D12 rewrite of Rune) are explicitly marked as **published / unrun locally** — zero numbers are extrapolated or fabricated.

### Top Headline Switches (Measured on This PC)

1. **`mimalloc` global allocator in `exo-ui.exe`** (2-line change, MIT): **9.53x faster** UI element-tree churn (`303.0 ms → 31.8 ms`) and **4.18x faster** cross-thread RPC string handoffs (`81.2 ms → 19.4 ms`) vs Windows `HeapAlloc`. (`snmalloc-rs` was **22.7x slower** than `mimalloc` on Windows MSVC — do NOT switch to `snmalloc`!)
2. **Build our own `exo-wire` binary RPC codec (`lab/own-rpc-codec`)**: **11.78x faster** live cross-process Windows Named Pipe RTT (`5,322.9 µs → 451.9 µs`), **33.4% smaller** payloads (`68,731 B → 45,769 B`), **1.97 GB/s** raw media frame pipe throughput (`66.5 µs` per 128 KiB frame), and **unblocks .NET NativeAOT** by removing reflection JSON.
3. **Build our own `exo-delta` binary delta updater (`lab/own-delta-pack`)**: Cuts a real 1,039-file Exo update download by **83.3%** (`19.68 MB → 3.28 MB` at L19; `21.95 MB → 4.12 MB` at L12 in 4.95 s build), with **127 ms** client apply + full BLAKE3 cryptographic verification across all 380.02 MB.
4. **Drop `tract` + `sherpa-onnx-c-api.dll` by unifying DeepFilterNet3 + TitaNet on existing `onnxruntime.dll`**: Eliminates **~55 MB** of redundant native DLLs (`50.64 MB exo-deepfilter.dll + 4.55 MB sherpa-onnx-c-api.dll`), cuts DeepFilterNet cold-start from **1,932 ms** and **+79.9 MB RSS**, and changing `SpeakerModel.cs` `num_threads: 1 → 2` immediately gives **1.67x faster** TitaNet embeddings (`52.85 ms → 31.67 ms`, p95 **2.13x** better: `97.83 ms → 45.88 ms`).
5. **SQLite tuned PRAGMAs (`WAL + synchronous=NORMAL + mmap_size=64MB`)**: **14.4x faster** batched inserts (`99.30 ms → 6.88 ms`) and **18.5x faster** point reads (`7,436 qps → 137,415 qps`) with zero new dependencies.
6. **Build our own `exo-tune` game-tuning DSL (`lab/own-tune-dsl`)**: Zero external crates, **269 KB** standalone compiler+patcher, compiles all 12 games from `GameSettings.Catalog.cs` (28.1 KB C#) into **6.36 KB** binary `.exotunepack` (hot-updatable without shipping `ExoLauncher.exe`), enforces anti-cheat / install-folder / no-FPS-cap / no-V-Sync invariants **at compile time**, evaluates all 12 games in **44.0 µs**, and patches XML configs in **14.5 µs**.
