# Spec 02 — Exo Upscale & FG Bridge (`exo-upscale` + `exo-fg-bridge`): Clean-Room Upscaler Vault & Offline Frame-Gen Proxy

- **Inventory Rank:** #02 · **Verdict:** `BUILD-OWN-NOW` · **Effort:** `XL`
- **Replaces:** Third-party GPL-3.0 `OptiScaler`, `dlssg-to-fsr3`, `MFG Unlocker`, `dlssg_for_sm86`, and `DLSS Swapper` archive dependency (`Services/DlssSwapService*.cs`, `Helpers/FrameGenRouter.cs`)
- **Anti-Cheat Class:** Split strictly into two tiers per `Services/AntiCheatCheck.cs`:
  - `exo-upscale` (vendor-signed DLL swaps): **`AC-SIGNED-DLL`** (allowed on `None`; allowed on `Found`/`PossiblyVac` only with explicit per-game consent naming exact AC; **never** Riot/Vanguard or `Unknown`).
  - `exo-fg-bridge` (proxy DLL): **`AC-OFFLINE-ONLY`** (`AntiCheatCheck.Kind.None` only, or Steam offline non-AC launch entries via session deploy + auto-removal on exit; **`Unknown` ALWAYS counts as Online/Blocked**).
- **License:** MIT (`exo-upscale` & `exo-fg-bridge`); vendor upscaler DLLs remain unmodified under their respective NVIDIA/AMD/Intel SDK licenses (`KEEP`, Row #47).

## 1. Scope

### What It Solves
Today Exo depends on external community GitHub releases (`OptiScaler` GPL-3.0, `dlssg-to-fsr3` GPL-3.0, `MFG Unlocker`, `dlssg_for_sm86`) and `dlss-swapper-downloads.beeradmoore.com` for older upscaler DLLs. Upstream releases break unpredictably, carry mixed GPL/binary-blob licenses, require INI configuration files, and leave Exo vulnerable to third-party archive downtime.

### In Scope
1. **`exo-upscale` (MIT Rust Vault & Manager):**
   - Direct automated indexing of official vendor GitHub SDK releases (`NVIDIA/DLSS`, `GPUOpen-LibrariesAndSDKs/FidelityFX-SDK`, `intel/xess`) mirrored into Exo's own signed R2 manifest (`updates.getexo.app`) — zero dependency on DLSS Swapper's server.
   - PE version + Authenticode signature verification (`WinVerifyTrust`) checking exact publisher (`NVIDIA Corporation`, `Advanced Micro Devices, Inc.`, `Intel Corporation`) before any DLL is cached or deployed.
   - Automatic NVAPI DRS NGX override configuration (e.g., DLSS 4 Transformer Preset K / latest model override) without touching game files at all when the NVIDIA driver supports native DRS override!
   - Content-addressed atomic backup & instant rollback of original game DLLs (`%LOCALAPPDATA%\ExoLauncher\upscaler-backups\`).
2. **`exo-fg-bridge` (MIT Rust Clean-Room Offline DX12/Vulkan FG Proxy):**
   - Lightweight, clean-room MIT DX12 (`dxgi.dll` / `version.dll` proxy) implementing:
     - Intercepting DLSS-G / Streamline swapchain + motion-vector/depth-buffer hooks in **offline non-AC games** and routing to official AMD FidelityFX FSR 3.1 FG (`amd_fidelityfx_dx12.dll`) or Intel XeSS FG (`libxess_fg.dll`).
     - Minimal clean-room `fakenvapi` capability shim for AMD Radeon / Intel Arc GPUs so games expose their native DLSS/FG settings without third-party binaries.
     - Zero ImGui overlay bloat — controlled cleanly via a tiny local named-pipe/JSON config generated by Exo before game launch.
   - **Transactional Session Deployment (`SessionMods`):** Writes a journal entry before deploy, removes proxy DLLs automatically on game exit, AND cleans any orphaned files on next Exo startup if the PC lost power mid-game!

### Out of Scope
- Bypassing anti-cheat or deploying proxy DLLs into any game with anti-cheat or `Unknown` status.
- Redistributing proprietary NVIDIA kernel blobs (`dlssg_for_sm86` binary kernels are dropped permanently).

## 3. Automation & Intelligence Design

1. **Zero-File-Touch First (NVIDIA):** On RTX cards with supported drivers, `exo-upscale` prefers **NVAPI DRS NGX Override** (`AC-SAFE`!) before swapping any DLL on disk — works even on anti-cheat games without touching a single file!
2. **Per-Game Auto-Update:** Automatically detects outdated DLSS 2.x/3.x or FSR/XeSS DLLs across the entire library and offers 1-click "Keep all upscalers current" (or automatic background update for `AntiCheatCheck.None` games).
3. **Zero-INI FG Bridge:** Reads game engine + GPU vendor + display Hz, automatically selects the best FG backend (Native → DRS Override → `exo-fg-bridge` FSR 3.1/XeSS for offline → `exo-flow` Spec #01 for online/legacy), deploys atomically on Play, and cleans up on Exit.
4. **Regression Auto-Rollback:** If `exo-present` detects a crash-on-launch (exit within 15 s with non-zero code) after a swap or FG bridge deploy, Exo automatically restores the original DLL/removes the bridge and flags that version as incompatible for that game.

## 5. Verification Gates

1. `cargo fmt --all -- --check`, `cargo clippy --workspace --locked -- -D warnings`, `cargo test --workspace --locked`.
2. **Anti-Cheat Policy Exhaustive Test Matrix:** Unit tests verifying `policy.rs` refuses `exo-fg-bridge` for `Found`, `PossiblyVac`, `Unknown`, and `Riot` — **100% pass required**, mirroring `ExoLauncher.Tests/AntiCheatCheckTests`.
3. **Authenticode Tamper Test:** Flip 1 byte in a test DLL; `verify.rs` MUST reject it before touching the target folder.
4. **Journal Crash-Recovery Test:** Simulate power loss mid-session; verify `journal.rs` removes every placed proxy file and restores original files byte-for-byte.
5. **Network Policy Gate:** Update `NetworkDestinations.cs` / Rust equivalent; zero calls to `dlss-swapper-downloads.beeradmoore.com`.

## 6. Safety Rules & Hard Stops

- **Hard Stop:** NEVER deploy `exo-fg-bridge` into any game with anti-cheat, `PossiblyVac`, `Unknown`, or Riot/Vanguard. `Unknown` ALWAYS counts as protected.
- **Vendor License Compliance:** Unmodified vendor DLLs (`nvngx_dlss*.dll`, `amd_fidelityfx_*.dll`, `libxess*.dll`) MUST retain their vendor license notices and never be binary-patched.
- **No Reverse Engineering of Proprietary SDKs:** Never decompile `nvngx_dlssg.dll` or `libxess.dll`; interact strictly via documented public SDK headers/interfaces.
- **Rollback First:** Backup original file hash + bytes BEFORE replacing; abort transaction if backup write fails.
