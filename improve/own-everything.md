### Headline Strategic Verdicts

1. **Immediate Footprint & Latency Liberation (Measured Baseline on this PC: `380.02 MB` installed across `1,039` files):**
   - Unifying DeepFilterNet3 + TitaNet on the already-shipped `onnxruntime.dll` (**Spec #03**) deletes **55.19 MB** (`exo-deepfilter.dll` 50.64 MB + `sherpa-onnx-c-api.dll` 4.55 MB) and kills **1,932 ms** cold load / **+79.9 MB RSS**.
   - Replacing the GPL-3.0 `SCSKiller` fork (**Spec #04**) deletes **~68 MB** (duplicate .NET 10 CoreCLR + 11.06 MB `BouncyCastle` + 6.79 MB `CUE4Parse` + unused `Velopack`) and removes the GPL-3.0 process boundary.
   - Replacing AGPL-3.0 `@openmouse/protocol` React/iframe (**Spec #05**) eliminates the entire `mouse/` Node/Vite/iframe stack and expands native HID control across Finalmouse, Wooting, Logitech, Razer, Pulsar, and Lamzu.
   - Replacing paid **$7 Lossless Scaling** (`LosslessScalingConfig.cs`) with **Exo Flow** (**Spec #01** — 100% free native DX12 optical-flow frame generation) + **Exo Upscale & FG Bridge** (**Spec #02**) gives every GPU free, zero-config, per-game frame generation.
   - Replacing NSIS + C++/WebView2 `ExoSetup.exe` + PowerShell delta scripts with **Exo Delta Installer** (**Spec #19**, backed by `lab/own-delta-pack` real measurements) cuts update downloads by **83.3%** (`19.68 MB → 3.28 MB`) and applies updates in **127 ms** with full BLAKE3 verification.
2. **.NET 10 Host → Rust Migration Verdict (`BUILD-OWN-NOW`, Phased 5-Stage Plan — Spec #20):**
   - **Verdict:** **Port incrementally behind `exo-wire` (Phases 0–5); do NOT do a big-bang rewrite.**
   - **Why:** The `.NET 10` host is `207,483` LOC across `804` files (`118.6k` Services, `31.6k` Adapters, `26.2k` Helpers, `24.1k` DiscordClient, `18.0k` WebHostBridge) and ships **~120 MB** of runtime/WinUI3/WASDK overhead (`~62 MB` WinUI3/WASDK/Win2D + `~58 MB` CoreCLR/BCL/R2R) plus GC pauses and dual-language maintenance.
   - **Fastest wins first:** Phase 0–1 retires WinUI3/WASDK from the host (**-62 MB**), ships `exo-wire` binary IPC (**11.78× faster** live pipe RTT measured on this PC: `5,322.9 µs → 451.9 µs`), and enables `.NET NativeAOT` as an interim bridge while Rust crates (`exo-hw`, `exo-autopilot`, `exo-stores`, `exo-discord`, `exo-host`) absorb subsystems one-by-one until `ExoLauncher.exe` + `exo-ui.exe` unify into a **single native Rust binary (<75 MB on disk, <120 MB idle RAM, <250 ms cold start)**.
3. **WebView2 Remaining Surfaces Verdict (`KEEP` lazy CompositionController + shrink surface area):**
   - `lab-web-in-rune` proved on this exact PC (`RTX 3070`, Windows 11 x64) that **lazy `ICoreWebView2CompositionController` in Rune** with `MemoryUsageTargetLevel::Low`, `TrySuspend()` (`~23 MB` child WS), and `Resume()` + `Close()` destroy (**100% RAM reclaimed to 124.9 MB pure Rune / 1 proc**) beats CEF (`428.8 MB` bundle, broken H.264/Widevine), Servo (`33 s` cold start, blank Discord), and Blitz (no JS). Meanwhile `lab-auth-native` already proved pure-Rust Discord QR (`424 ms`) and Steam protobuf sign-in, eliminating WebView2 from routine sign-in flows.
4. **Build / CI / Release Pipeline Verdict (`BUILD-OWN-LATER` unified `cargo xtask` after Rust host Phases 1–3):**
   - Today's release requires 5 toolchains (`dotnet`, `cargo`, `npm/node` ×2, `cmake/msvc` + `meson` + `vcpkg`, `NSIS makensis.exe`). Executing Specs #03, #04, #05, #06, #19, and #20 collapses this to **Rust (`cargo`) + optional C/C++ voice vendoring**, cutting release build complexity and CI wall-clock time dramatically.

## Anti-Cheat & Safety Classification (Law: `Services/AntiCheatCheck.cs`)

Every row and every spec enforces Exo's non-negotiable rules (`apps/launcher/AGENTS.md` & `Services/AntiCheatCheck.cs:108-159`):

| Class Code | Definition | Permitted Operations |
| --- | --- | --- |
| **`AC-SAFE`** | External / OS / Hardware / Driver / ETW / HID / UI / Cloud — zero injection, zero game-file writes, zero `OpenProcess` handle to game. | Allowed on **all** games including Vanguard, EAC, BattlEye, FACEIT, ACE, Ricochet, VAC, and Unknown. |
| **`AC-OWN-IFACE`** | Game's own config files (`INI`/`JSON`/`XML`), standard launch options (no anti-cheat bypass flags), regenerating cache folders while game closed. | Allowed on `None`, `Found`, `PossiblyVac`; **never** Riot/Vanguard, **never** `Unknown` (`AntiCheatCheck.Allows`). |
| **`AC-SIGNED-DLL`** | Swapping an existing upscaler DLL for a newer **vendor-signed** (Authenticode-verified) DLL of the same vendor. | Allowed on `None`; allowed on `Found`/`PossiblyVac` **only** with explicit per-game consent naming the exact anti-cheat; **never** Riot/Vanguard or `Unknown`. |
| **`AC-OFFLINE-ONLY`** | Any placed file, proxy DLL, hook, FG mod, shader recorder, or injected overlay (`Category.Placed`). | Allowed **strictly** on `AntiCheatCheck.Kind.None` (or explicit Steam non-AC offline launch entry via `DlssSwapService.SessionMods.cs`, auto-removed on exit). **`Unknown` ALWAYS counts as Online/Protected.** |
| **`AC-HARD-STOP`** | Touching `vgk`/`vgc`/EAC/BE drivers/services, killing anti-cheat process trees, DRM bypass, modifying game `.exe` binaries. | **FORBIDDEN everywhere.** |

#### Why Porting to Rust Wins — And Why Big-Bang Would Fail

- **Why Port to Rust (`BUILD-OWN-NOW`):**
  1. **Disk footprint (`380.02 MB → <75 MB`):** Eliminating CoreCLR + BCL + WinUI3/WASDK + duplicate Shaders CoreCLR + `tract` + `sherpa-onnx` + GPL Python CLIs removes **>300 MB** of redundant runtimes.
  2. **Memory & cold start:** A single Rust binary with `mimalloc` starts in **<250 ms** and idles under **120 MB WS** (pure Rune idle already measured at **117–124 MB WS** in `lab-web-in-rune`), eliminating the second process (`ExoLauncher.exe` + CoreCLR GC heap ~150–250 MB) and eliminating IPC serialization copies entirely once merged.
  3. **One language, zero FFI boundary tax:** `529` P/Invokes and `39` COM declarations are *already* calling Win32/DXGI/ETW/NVAPI/NVML/ADLX/IGCL/WASAPI/HID — Rust's official Microsoft `windows` crate gives zero-cost typed bindings with compile-time safety, no GC pinning (`GCHandle`), and no dual DTO maintenance between C# `WebHostBridge*.cs` and Rust `exo-rpc`.
- **Why Big-Bang Fails:** Rewriting `207,483` LOC of battle-tested Windows store quirks, anti-cheat guards, and Discord client logic in one shot would stall shipping for 6–9 months and regress subtle edge cases.

### 2B. WebView2 for Remaining Web Surfaces

Grounded directly in **`lab/lab-web-in-rune:improve/lab-web-in-rune-report.md`** (measured on this PC: RTX 3070, Windows 11 x64, EdgeWebView2 `158.0.4370.33`):

- **Architecture:** Single shared `ICoreWebView2Environment` + lazy `ICoreWebView2CompositionController` mounted into Rune's DX12 DirectComposition visual tree **only** when a user enters a surface that truly requires a browser engine.
- **Lifecycle discipline:**
  - **Idle (never opened):** Pure Rune = **120 MB WS / 152 MB Priv / 1 process (0 WebView2 children)**.
  - **Active (e.g., hidden Spotify/Apple Music Widevine audio or interactive OAuth captcha):** `MemoryUsageTargetLevel::Low` + `--disable-gpu` for audio-only/login pages (**-53% to -67% child Private Bytes** vs GPU-on).
  - **Hidden (leaving Music room):** Immediate `TrySuspend()` trims child WS to **~23 MB** (total **148.4 MB WS**).
  - **Dismissed (sign-in complete / Music idle >10 min):** `Resume()` + `Close()` reclaims **100% of browser memory** back to **124.9 MB WS / 1 process** in `0.26–3.67 s`.
- **Shrink WebView2 surface area to near-zero:** Graduate `lab-auth-native` (Discord QR, Steam Protobuf, system-browser PKCE) and native Store trailer playback (`video_decoder.rs`), leaving WebView2 strictly for Widevine DRM music engines and rare interactive captcha/2FA pages.
