# System Tuning & OS Playbook Evidence Table

Audit of every Windows OS, scheduling, power, memory, storage, network, and overlay tweak in Exo Launcher (`apps/launcher/ExoLauncher/Services/SystemTuning*.cs`, `Autopilot*.cs`, `NetworkTune.cs`, `PcHealth.cs`, `OverlayAdvisor.cs`, `GameQosPolicy.cs`, `GameSessionDownloadPause.cs`) against empirical research in `r-os-net-tweaks.md`.

Verdicts:
- **Keep (Default / Auto)**: Measurable benefit or safe recovery of a broken Windows default; no security or stability regression.
- **Keep (Opt-In / On-Demand)**: Measurable benefit on specific hardware or trade-off (power, security, or compatibility); requires explicit user opt-in.
- **Demote to Opt-In + Migrate**: Previously applied by default in the Deep Playbook, but evidence shows regression or trade-off as a blanket default; moved to Opt-In and reverted once where Exo set it.
- **Retire + Migrate**: Myth or harmful on current Windows 10/11; stopped applying and reverted once where Exo set it.
- **Added**: High-impact evidence-backed tweak from the Top 30 / Harmful Tweak Cleaner added in this pass.
