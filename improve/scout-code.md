## 3. Ranked Proposals (Player-Felt Impact ÷ Effort)

Top 10 proposals have ready-to-dispatch worker specs in `improve/scout-code-specs/`. Proposals #11–#18 complete the exhaustive sweep.

### Rank #1 — Headless NativeAOT Host for v4 + Zero-Wait Speculative Boot (`spec-01`)
- **What it beats & measurable target:** Beats current WinUI 3 host (`managedEntryMs=303 ms`, `winuiMs=271 ms`, host private RAM `175 MB`, ~60+ MB WinAppSDK/WinUI/Win2D DLLs) and every major PC launcher (Steam 3–6 s, Epic 4–8 s, Playnite 1.2 s). **Target:** Host cold start `<35 ms`, `exo-ui` first interactive Library frame `<50 ms` (via memory-mapped `library.mmap` snapshot), host private RAM `<35 MB`, `-85 MB` install footprint.
- **Evidence it's possible:** Static audit proved there are ONLY **4 `[ComImport]` interfaces** in all 206,822 LOC (`CoverArtService.cs:1598-1680` — trivial WIC wrappers replaceable with `[GeneratedComInterface]`). `ExoLauncher.SteamIpc` (2.86 MB) and `ExoCapture` (4.56 MB) ALREADY ship on **.NET 10 NativeAOT** in this exact repo. In v4, `exo-ui.exe` owns all UI; `CoreWebView2` for hidden music/auth only needs a 50-line Win32 `CreateWindowExW` HWND, and single-instance activation only needs a Win32 Named Mutex + pipe message (zero `Microsoft.Windows.AppLifecycle` / WinUI 3!).
